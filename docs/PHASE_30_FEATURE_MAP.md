- Service discovery
- Scheme discovery
- My SETU
- Profile
- Document Vault
- Application journeys
- Grievance registration/tracking
- Notifications
- SETU Assistant
- Maharashtra intelligence
- Accessibility

## Officer layer

- Officer dashboard
- Department queue
- Assignment/reassignment
- Review
- Approve/reject
- Officer notes
- SLA visibility
- Notifications

## Admin layer

- Admin dashboard
- Operations
- Command center
- Department workload
- Application metrics
- Grievance queue
- Audit visibility
- Integration visibility

## Platform layer

- Authentication
- RBAC
- Consent
- Document metadata
- Persistence abstraction
- PostgreSQL/Supabase adapter
- Connector contract
- Webhook signatures
- Idempotency
- Retry policy
- Dead letters
- Notifications
- Metrics
- Security hardening
- Accessibility
- CI/CD
- Docker deployment

## Important boundary

The platform architecture is integration-ready, but live government department
integration depends on official APIs, contracts, credentials, approval and
verified service metadata.
