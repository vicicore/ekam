# SETU Phase 30 — Final SIH Demo Script

## Demo objective

Demonstrate one complete citizen journey instead of showing disconnected features.

## Recommended 7–10 minute flow

### 1. Landing
Open `/`.

Show:
- SETU identity
- citizen-service navigation
- language selector
- service discovery
- application tracking
- schemes
- grievance
- assistant

Narration:
"SETU brings citizen-facing services, documents, applications, tracking and support into one structured journey."

### 2. Service discovery
Open `/services`.

Select a service and show:
- description
- department
- required documents
- application action

### 3. My SETU
Open `/profile`.

Show:
- profile
- applications
- documents
- pending actions

### 4. Document Vault
Open `/vault`.

Show reusable document records and verification status.

### 5. Application Journey
Open `/journeys`.

Open one application.

Show:
- workflow stages
- current status
- consent
- department stage
- next action
- timeline

### 6. Officer workflow
Open `/officer` or `/officer/queue`.

Show:
- department queue
- assignment
- review
- decision

### 7. Integration
Open `/integrations`.

Show:
- connector
- external reference
- integration status

Explain that actual government API adapters are connected only where approved API contracts/credentials exist; the demo uses the configured sandbox boundary.

### 8. Notification
Open `/notifications`.

Show:
- application update
- assignment/update notification
- read/unread state

### 9. Assistant
Open `/assistant`.

Ask:
"How do I track my application?"

Show:
- grounded response
- source
- action link

### 10. Maharashtra intelligence
Open `/maharashtra/intelligence`.

Show:
District → Department → Service.

### 11. Admin command center
Open `/admin/command-center`.

Show:
- application volume
- department workload
- SLA visibility
- audit activity

## Closing line

"SETU is designed as an integration-ready citizen service layer: one citizen journey, reusable information, traceable department workflow, secure integration boundaries and multilingual access."
